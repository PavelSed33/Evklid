# Евклид

Учебный адаптивный сайт для портфолио. Сохранены оригинальные фотографии, цвета, типографика и структура проекта.

Демо: https://pavelsed33.github.io/Evklid/

## Работа интерфейса

- Меню закрывается после перехода, по Escape и по клику вне панели. Скрытое меню исключено из клавиатурной навигации.
- Поиск ищет текст по разделам страницы, показывает отсутствие результатов и открывает найденную вкладку/ответ.
- Четыре этапа переключаются мышью и стрелками клавиатуры; Home и End ведут к первой и последней вкладке.
- FAQ использует кнопки с состоянием раскрытия. Кнопка расчёта ведёт к форме.
- Форма проверяет имя, email и согласие. Демонстрационные данные никуда не отправляются; сервер не подключён.
- Кнопки документов и неподключённые внешние ссылки показывают пояснение учебной версии.
- Адаптивные исправления покрывают узкие экраны, планшеты и телефон в альбомной ориентации. Учитывается уменьшение движения.

Запуск: `python3 -m http.server 5173`, открыть http://localhost:5173. Проверки Chromium и скриншоты доступны в GitHub Actions → Check Evklid → артефакт `evklid-screenshots`.
